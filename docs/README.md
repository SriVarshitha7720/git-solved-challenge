## Quick Start
1. Clone the repository
2. Configure environment variables
3. Run deployment script

## Development Setup
1. Install dependencies: `npm install`
2. Configure environment variables
3. Run in development mode: `npm run dev`
4. Access dashboard at `http://localhost:3000`
